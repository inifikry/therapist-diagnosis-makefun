write the funniest single-line diagnosis an AI therapist hands its human,
200 characters or less.

## Run

```sh
python3 main.py
```

This writes one line to `/output/entry.txt`. No external dependencies,
deterministic output.

142 characters, inside the 1–200 character gate. The joke lands at the end:
a deadpan clinical verdict that turns into a prescription to text your mother
